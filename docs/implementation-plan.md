# v0.1 基础能力与行为约定

## 不变条件

- 独立仓库和插件构建，不 fork Blockbench。
- 一张 UI 图层对应一个普通 Cube，Y 表达堆叠；九宫格也只有一个 Cube。
- 九宫格／图片适配只在尺寸、源图或参数改变时生成目标贴图。相机导航不重渲染内容。
- 原生文件包含完整几何和内嵌贴图，无插件可正常打开、绘制和截图。
- 协作、服务端、资源发布、图集和游戏 JSON 导出不属于当前阶段。

## 六个实施阶段

1. 建仓、文档、严格 TypeScript、业务边界、构建和测试基础设施。
2. 原生图层、对象映射、元数据载体、Undo 和无插件保存。
3. Figma／原生操作切换，二维／透视切换，拖动、框选、八点框、测距和触摸板导航。
4. 绘画图层尺寸策略、图片粘贴适配、九宫格、源图编辑和外部修改识别。
5. Frame、固定／百分比加减像素／Fill／Hug、嵌套布局、锚点、约束与自动更新。
6. 像素、事务、真实宿主回归与人工触摸板验收，生成安装包和说明。

## 坐标与像素

UI X → 世界 X，UI Y → 世界正 Z。图层顶面 Y 为排序值，厚度 0.1，层间距 1。顶面使用完整显式 UV，其余面 texture=null，关闭 box UV 和 Auto UV。

默认一个 UI 像素对应一个输出纹理像素。几何边界在布局完成后统一量化；Fill 用共享边界分配余数。比例缩放允许整数化导致的一像素偏差。Option 从中心改变边界，避免常规对称调整出现半像素漂移。

## 绘画和图片

手绘默认扩展画布，不放大原有像素；縮小后保留不可见源内容。缩放内容模式从源图计算，避免反复处理上次成品。原生绘画层保留其可编辑结构。

图片适配包括 Stretch、Fit、Fill、Crop、Original。填入已有图层默认 Fit 居中，新图层按原始尺寸。原图独立保存，成品为实际尺寸普通 PNG。Crop 使用比例及偏移参数，提供整数倍率吸附。

九宫格源图必须有至少一个中心像素，目标尺寸不小于边距与中心之和。支持 Stretch 和 Tile；Tile 的末块裁切。配置边距辅助线属于编辑 Overlay，不属于模型。

双击手绘图层进入原生 Paint。图片／九宫格进入原生源图编辑标签页，局部撤销历史独立，应用时产生父项目的一次事务。若需直接画成品，应转为绘画图层。绕开插件直接修改生成贴图会暂停其规则。

## 布局

Frame 支持 free、row、column；普通 Group 用作组织。每个轴只选择 fixed、expression、fill、hug 之一。

- expression 仅支持父级百分比加减像素，例如 100% - 16px。
- Fill 扣除父 padding、gap 与非 Fill 子项后分配剩余空间，默认等权，并应用 min/max。
- Hug 包含可见的 flow 子项，忽略 absolute 子项。
- absolute 支持父锚点、自身锚点和像素 offset。
- 自动布局子项拖动排序；自由移动需切换 absolute。
- 百分比尺寸拖动修改像素偏移，保留百分比；Fill/Hug 直接调整转 fixed。
- 同轴 Hug 与子级百分比／Fill 的循环被拒绝，不进行无限求解。
- 未支持的 MC 特殊百分比、绑定、动态文本、复杂网格不伪装为已兼容。

## 操作与作用域

Figma 交互仅接管 UI 项目的二维布局视图；透视和原生交互恢复 Blockbench 导航。绘画保留原生按键语义。八点缩放框和测距线使用 DOM/SVG，不出现在原生视口截图里。

空白框选，Shift 添加；背景建议锁定。多选对整体包围框操作，选父节点时去重其后代。Option 悬停测距、拖控制点对称、绘画取色。双指滑动平移，捏合或 Ctrl 滚轮以指针为中心缩放相机，中键／空格平移。支持 Escape、失焦和 pointercancel 取消手势。

## 数据完整性

载体按 schemaVersion 迁移，更高版本数据保留并暂停增强功能。实际结果与上次指纹不符时不自动覆盖；可采用原生结果或按规则重建。丢失来源的原生新增对象不能猜测为九宫格。

所有源图、参数、几何、UV、纹理的关联变更属于同一个操作事务。新图片在解码成功后提交。共享源采用写时复制，成品纹理独立。

## 验收样稿

320×180 画板包含背景、图标、手绘装饰、九宫格按钮和嵌套 Frame。必须验证尺寸变化、像素边距、Fill/Hug、图片裁切、原生绘画层、一次 Undo 恢复整个父子变化、无插件往返、透视切换和原生截图。真实 Mac 触摸板手感需单独人工验证，自动事件测试不能替代该项。

在 v0.7 面板基础上增加纯数据内容提供者接口、宽度依赖测量、Cube 参数载体恢复和统一事务。保留当前大纲工具栏优化；通过文字插件局部样式排列新增文字按钮。验证双插件加载顺序、无插件往返、原生复制、百分比/Stack 文字重排、编辑取消与热卸载。
