# v0.1.0 验证记录

验证日期：2026-09-22。

## 已通过

- `npm run check:boundaries`：业务内核与宿主适配器的依赖隔离。
- `npm run typecheck`：严格 TypeScript，包括没有 DOM 类型的 Domain/Application 编译。
- `npm test`：4 个测试文件、34 个用例。
- `npm run build`：生成单文件插件 `dist/mcui_studio.js` 和调试 source map。
- `npm run test:host`：8 个真实 Blockbench 页面测试，全部通过。
- `npm audit`：当前锁定依赖无已知漏洞。
- 实际页面截图人工检查：八点框和烘焙九宫格正确显示；属性面板可以滚动访问九宫格设置。

宿主是独立缓存副本中的 Blockbench **5.2.1 / e2ede0809ee6bc91f374ac7e00d34cffbdf86a14**，使用 macOS 上的无头 Chrome 和软件 WebGL。原始 Blockbench 源码仓库未修改。

真实宿主测试覆盖：

1. 九宫格只产生一个标准 Cube；成品纹理尺寸匹配目标；Undo/Redo 与无插件页面保存。
2. 八点框实际鼠标拖拽、二维／透视切换、卸载清理。
3. 原生绘画层、缩小再扩展后的像素保留、原生尺寸工具。
4. 父布局驱动两个九宫格，一次 Undo 恢复所有尺寸与纹理。
5. 原生源图编辑标签页、应用与撤销。
6. 无插件修改不会自动覆盖，重新启用后采用结果保留当前位置。
7. 真实鼠标双击进入原生画笔并绘画；缩放事件不改变模型尺寸或编辑历史。
8. 绘画层缩放后的实际像素分辨率与正常 scale；复制后的绘画层独立可编辑。

## 仍需实机验收

- Mac 真实触摸板的惯性、捏合连续性与手感；自动化 WheelEvent 不能代替这项验证。
- Blockbench 5.2.1 桌面版的完整操作、系统剪贴板权限和真实图片粘贴。
- 团队真实素材中的半透明叠加、长时间绘画、大量图层下的性能。

这台 Mac 当前安装的是 Blockbench **5.1.6**，未更改该安装或其用户配置。插件最低版本固定为 5.2.1；不能据当前 Web 宿主测试宣称已经验证 5.1.6 桌面版。

## 已知范围

首版不实现游戏运行时绑定、动态文字排版、复杂网格、协作和资源发布。原生格式转换不保证保留插件规则。

内部跨项目粘贴保留 UI 参数与源图像；原生绘画分层快照目前以 `.bbmodel` 项目文件和同项目复制为保留路径，不承诺跨项目剪贴板传递全部原生绘画分层。
