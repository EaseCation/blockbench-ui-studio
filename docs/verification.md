# v0.3.0 验证记录

验证日期：2026-09-23。宿主仍为隔离的 Blockbench 5.2.1 Web 构建，macOS Chrome／软件 WebGL；未修改用户的桌面配置。

## 功能验收

- 原生“UI 内容”字段设置双色线性渐变、向内描边；像素颜色断言与真实截图一致。一键栅格化前后图像一致，Undo 恢复规则。
- 128×64 图片缩小为 32×16 UI 时，纹理 PNG、纹理尺寸、UV 和 UV 尺寸完全不变；撤销恢复几何尺寸。无插件页面加载序列化项目后保持 32×16 几何和 128×64 贴图。
- 选中图层立即选择对应贴图与顶面 UV，原生面板显示真实 48×32 尺寸，无需进入绘画。
- 顶视相机不渲染原生网格／轴辅助；放大后全视窗显示淡色像素网格。透视和插件卸载恢复原生辅助与方向控件。
- 直接绕过插件绘制带外观的成品时暂停规则，保留新像素；显式栅格化后恢复正常绘画，避免背景与透明度重复合成。
- 真实截图检查确认填充／描边字段与栅格化按钮可见，顶视图没有中心轴、原点十字或方向控件。

## 自动验证

- `npm run check`：依赖隔离、严格 TypeScript、45 项单元测试及构建通过。
- 24 项宿主场景通过，证据为完整 23 项运行中的 22 项通过，加上 7 项相关场景定向重跑（含新增直接绘画保护场景）。完整运行唯一失败来自测试保留原生 raw 编译对象后执行 Undo，原生数组引用随 Undo 改变；改为真实 JSON 序列化快照后，无插件往返测试通过。
- 最后调整卸载清理顺序后，额外重跑二维交互／卸载和网格恢复两项。
- 原有九宫格、原生分层、框选、大纲、源图、表达式和 Undo 场景继续通过。

## 范围与手工验证

渐变当前为双色线性渐变，描边为矩形向内整数像素描边。保留分辨率固定整张成品纹理，非等比修改 W/H 会拉伸显示；如需按图层尺寸重建适配，切换“跟随图层尺寸”。九宫格保持目标尺寸烘焙。

真实 Mac 触摸板手感、桌面版剪贴板权限以及大量图层的长期性能仍需实机验证。像素网格是编辑辅助，不进入原生截图。
