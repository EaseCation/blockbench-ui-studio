# 多选属性：Figma 对照与 UI Studio 规则

调研日期：2026-09-24。实现版本：0.12.0。

## 官方依据

[Figma：Adjust alignment, rotation, position, and dimensions](https://help.figma.com/hc/en-us/articles/360039956914-Adjust-alignment-rotation-position-and-dimensions) 的 Adjust values 一节以 `Mixed+100` 说明混合值选区：输入修改可以应用于所有所选图层，而不是仅修改首项。该文也区分了相对各自父级的操作，以及选区整体的操作。

[Figma：Guide to auto layout](https://help.figma.com/hc/en-us/articles/360040451373-Guide-to-auto-layout) 明确说明属性取决于布局类型与对象角色：布局容器和其子项的能力不同，流式子项的定位受布局控制，Ignore auto layout 后才可自由定位。其 Fill container、Hug contents 的适用范围也不同。

本轮参考上述多选和上下文原则。UI Studio 保留既定的游戏 UI 模型：Frame 负责容器布局，Image 负责可绘制内容；不会因为 Figma 的 Frame 可填充而改变这个约定。已有基岩尺寸表达式和 Fill/Hug 扩展继续保留，不另加入 Figma 的 `Mixed+…` 通用算式语法。

## 交互约定

| 情况                         | 显示与编辑                                                                                                           |
| ---------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| 全部值相同                   | 显示共同值，包括 0、false 和空的可选约束。颜色统一按等价的 RGBA 比较。                                               |
| 值不同                       | 输入实际值为空，淡色“混合”为占位提示；下拉无具体选项，九点控件无虚假选中，颜色显示混合图案。                         |
| 向混合字段输入明确值         | 对全部显式选区统一设置该字段。宽高、XY、四边参数分别判断，未编辑的轴/边保留各自值。                                  |
| 只聚焦、Enter 或失焦，未修改 | 不产生编辑，不把空白写成 0，也不把首项值复制给其它项。                                                               |
| Frame 与 Image 混选          | 保留共同尺寸、角度、适用的自身定位和限制；隐藏容器排列、内边距及 UI 内容专属板块。                                   |
| 自由 Frame 与 Stack 混选     | 可统一排列方向、编辑共同内边距；自动布局间距和子项对齐只在全体均为 Stack 时出现。                                    |
| 有流式子项受 Stack 控制      | XY 偏移禁用，锚点隐藏。Stack 与自由父级混选不显示会产生不同效果的定位角色控制。                                      |
| 子项属于 Image 容器          | 保留自由位置和锚点，隐藏不会改变 Image 素材 Hug 的“计入父级包裹”设置。                                               |
| 图片适配模式不同             | 模式本身可批量统一；Crop 独有参数只在全体 Crop 时显示。包含 Stretch 时不提供共同锚点；只允许缩小也按适用性交集显示。 |
| 部分对象没有填充/描边        | 可先统一填充类型或描边粗细；颜色暂时禁用，避免只对部分对象产生可见效果。                                             |
| 素材类型不同                 | 保留共同外观能力；特定素材的适配、切片和尺寸策略不作部分应用。来源编辑/替换等单对象操作禁用或隐藏。                  |
| 任何对象规则无效             | 整次批量编辑失败，文档和历史都不部分提交；错误草稿保留，可用 Escape 恢复。                                           |

位置数值仍是各自父级和锚点下的偏移，不变成多选包围盒的位置。相同尺寸表达式显示其共同规则，解析后的实际尺寸可能因父级不同而不同；下方实际尺寸摘要会另外提示混合。

## 架构

`application/inspector.inspectProperty` 只处理纯数据，区分不可用、共同值、混合值、逐轴值和不可编辑原因。`property-fields` 是字段读写和适用性注册表；`fieldState` 与 `writeField` 分别供所有展示和写入入口使用。

原生“元素”页和组合面板消费相同契约。原生表单仍由注册的 FormElement 承载，双轴及数值字段从逻辑显式选区读取共同值，避免宿主后续刷新再次写入首个 Group 的值。标量输入复用现有草稿、步进与拖动组件，不修改宿主原型。

混合状态只属于视图，不写入 `.bbmodel`、Cube/Group 属性或 Undo。所有修改仍通过 Studio 候选校验和单次事务；先检查整个选区的适用性，不跳过不支持的节点后继续修改剩余节点。原生历史和第三方文字协议保持不变。
