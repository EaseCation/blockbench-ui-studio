# 统一性能实验与架构优化

本轮基线为 UI Studio 0.8.2 + BBModel Text Component 0.2.1，优化版本为0.8.3 / 0.2.2。原始复杂样稿282逻辑节点、176 Image、70文字；另在临时宿主中复制成1128节点/280文字的压力文档。没有改动用户原稿或桌面配置。

## 实验方法

独立Blockbench 5.2.1 Web宿主、同一Chrome和SwiftShader设置，保留修改前的bundle。测量选择、普通位置编辑、文字修改、Undo/Redo、拖动与缩放预览、Hug文字、32项字体库；记录每阶段调用次数和CPU profile。表格使用每项首笔之后的中位数，Undo/Redo取两次中位数。脚本会改变临时文档以覆盖不同负载，结束后销毁上下文；不写回输入bbmodel。

另用1500个Fill子项测试布局分配，以及只加载文字插件的独立编辑场景。测量包含采样和计时开销，属于同机比较，不是各设备的延迟承诺。

## 已确认热点与处理

| 热点                                       | 处理                                                            | 失效边界                                                 |
| ------------------------------------------ | --------------------------------------------------------------- | -------------------------------------------------------- |
| 原生对象逐次find、多个模块独立扫描bindings | 活动项目复用宿主UUID表，统一BindingIndex；保存/恢复批量索引Cube | 项目与bindings替换；后台项目保留自身对象查找             |
| 选择触发整场景像素指纹读取                 | 独立ProjectPort.selection，只读取选区与实际原生祖先             | 仍由编辑/重开流程执行完整差异保护                        |
| 每个节点反复读取DOM边界，静止相机重复投影  | 批量投影＋每预览命中缓存                                        | 文档、scene、相机矩阵、viewport边界、选区与标签状态      |
| 每个Fill重复分配同父剩余空间               | 单次layout按父级/轴共享flow与分配                               | 每次求解重新计算，保留循环与min/max约束                  |
| 同样文字反复创建Canvas和测量               | 复用测量Canvas、单次字宽缓存、有界布局LRU                       | 文本、真实字体哈希、字号、宽度、字距、行高、对齐         |
| 每次字体查找都解析本机字体库               | 项目字体优先；库JSON仅变化时重新解析                            | 直接localStorage更新也会刷新；同字体ID换资源不复用旧测量 |
| 相同PNG/几何反复计算指纹                   | WeakMap仅保存最近相同输入的结果                                 | 任一输入变化重新计算，保存算法和schema不变               |

文字布局缓存最多1024条、1048576文本计量单位；单条超过16384不保留，避免长段落挤占缓存。缓存结果不可变，插件卸载清理测量状态。没有持久化新缓存字段。

## 可复用脚本

先启动隔离宿主：

```sh
MCUI_HOST_PORT=4193 node scripts/serve-host.mjs
```

另一个终端在仓库根目录运行：

```sh
node scripts/benchmark-host.mjs --model /path/to/design.bbmodel \
  --url http://127.0.0.1:4193 --out .cache/current.json
```

输入需同时包含普通Image和可编辑文字。脚本默认读取本仓库UI构建与同级文字插件构建，也可用--ui/--text指定旧版bundle进行对照。输出分为JSON计时结果、逐规模CPU profile和中间检查点；输出路径已存在会拒绝覆盖。启动的浏览器上下文独立于用户浏览器。

## 验证与剩余成本

新增回归覆盖Fill约束/共享边界/重新计算与循环拒绝，选择不走整场景扫描，投影随相机/节点/标签变化，300种不同文字缓存复用，以及宽度/行高/字距/字体身份/项目/本机库失效。原有外部像素保护、文字复制、无插件恢复、Undo、布局与绘画用例继续验证。

保留完整原生Undo和原生纹理解析语义。千级节点下，完整快照、宿主逐面查找纹理以及位图读写仍有成本。

最终验证：UI Studio check通过（69项单元测试、类型/边界/构建），完整宿主99项通过；文字插件check及完整宿主22项通过；两个仓库格式与差异检查通过。
