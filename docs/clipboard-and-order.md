# 图片填充、样式属性和图层排序（0.13.0）

参考 Figma 官方 [Copy and paste properties between layers](https://help.figma.com/hc/en-us/articles/4412765442967-Copy-and-paste-properties-between-layers) 与 [Adjust alignment, rotation, position, and dimensions](https://help.figma.com/hc/en-us/articles/360039956914-Adjust-alignment-rotation-position-and-dimensions)。前者说明属性粘贴应用目标支持的属性，以及 Mac Option+Command+C/V、Windows Ctrl+Alt+C/V；后者给出前后层级与首尾排序快捷键。

## 图片粘贴

复制外部图片后，选中一个 Image 并按 Cmd/Ctrl+V，将图片应用到该 Image 的内容填充。保留名称、位置、显示尺寸、描边、透明度和子图层；默认 Fit 居中，仍可在 UI 内容中切换 Fill、Stretch、Crop 等适配方式。原图保留为源素材，标准贴图用于无插件显示。

选择 Frame 时在内部新建 Image；没有单一目标时新建图层。“粘贴图片为子图层”始终新建。多张图片在同一目标内并列创建，整次导入只产生一次 Undo。

若原 Image 使用素材 Hug，换源可能改变其尺寸，因此替换时仅将 Hug 轴固定到替换前的实际尺寸；其它尺寸规则保留。操作开始时固定目标；异步读取/解码期间换选区、换项目或已有文档编辑会取消过期结果。正在执行视口手势时不应用剪贴板编辑。

## 属性范围

本轮采用用户确定的“样式复制”范围：Image 的填充（图片、绘画源或九宫格及其适配规则）、纯色/渐变、描边和透明度。复制一个 Image 后，可粘贴到多个 Image；不复制名称、位置、显示尺寸、旋转、锚点、自动布局、父级或子层结构。

文字组件只应用其支持的外观，文字内容、字体排版及组件身份保持不变，不用图片填充替换文字配方。Frame 不绘制自身内容，没有可复制的外观；多选中含 Frame 时跳过 Frame 并提示。任何可编辑目标校验失败会使整次属性粘贴回滚。

图片资源随样式快照携带，支持跨 UI 项目粘贴；每个目标使用独立源与成品纹理。剪贴板内容改变后不会继续套用旧样式；仅当系统剪贴板读取不可用时，才允许使用当前窗口中明确复制过的属性快照。

| 操作     | Mac          | Windows    |
| -------- | ------------ | ---------- |
| 复制属性 | Cmd+Option+C | Ctrl+Alt+C |
| 粘贴属性 | Cmd+Option+V | Ctrl+Alt+V |

入口同时位于元素右键菜单和工具菜单。复制属性只支持单个源 Image；粘贴可选多个目标。普通 Cmd/Ctrl+C 仍复制完整图层。

## 层级排序

| 操作     | 直接按键  | Figma Mac 组合 | Figma Windows 组合 |
| -------- | --------- | -------------- | ------------------ |
| 后移一层 | `[`       | Cmd+`[`        | Ctrl+`[`           |
| 前移一层 | `]`       | Cmd+`]`        | Ctrl+`]`           |
| 置于底层 | Shift+`[` | Cmd+Option+`[` | Ctrl+Shift+`[`     |
| 置于顶层 | Shift+`]` | Cmd+Option+`]` | Ctrl+Shift+`]`     |

四个命令均在元素右键菜单和工具菜单中可用。主快捷键与直接按键通过原生 Keybind/sub-keybind 注册，支持在快捷键设置中重新绑定。

排序以显示前后为准，通过原生 Y 层级表达。多选保留选中对象之间及其余对象之间的相对顺序；跨父级时各自在所属容器内排序，不换父级。选择父级时整棵子树一起调整，不重复移动已包含的后代。处于边界时不写空 Undo。自由布局只改叠放顺序；自动布局内部还会按新顺序重新排列。

这些新增样式和排序快捷键用于 UI 项目的 Figma 二维编辑上下文，输入框、重命名、对话框、绘画、透视、原生交互及未完成手势保留宿主行为；普通模型不接管。
