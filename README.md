# MC UI Studio

面向 Minecraft 像素 UI 的独立 Blockbench 插件。用原生 Cube 表达图层，用 X/Z 表达布局、Y 表达层级；图片和九宫格在尺寸变化时烘焙成普通贴图。

## 安装与开发

要求 Node.js 22+、Blockbench 5.2.1。桌面版和 Web 版使用同一个插件文件。

```sh
npm ci
npm run check
```

在 Blockbench 的 **文件 → 插件 → 从文件加载插件** 中选择 `dist/mcui_studio.js`。然后在开始页 **新建 → 总体 → MC UI** 中点击 **创建 MC UI 项目**，也可以双击 MC UI 直接创建。**工具 → 新建 MC UI 项目** 入口仍然可用。

MC UI 是原生创建入口，项目实际仍保存为通用模型（Generic Model）的 `.bbmodel`，未安装插件的客户端也能打开。

开发时运行 `npm run dev`，重新加载本地插件即可。源仓库不要求放在 Blockbench 目录中；构建也不依赖 Blockbench 源码路径。

## 工作方式

- 新项目为 320×180 的 Frame，默认使用正交顶视图。面板可以创建绘画图层、Frame、文件夹及导入图片。
- 切换“属性”标签编辑图层尺寸、父级、锚点、内容模式与布局。
- 宽高支持 `80px`、`100% - 16px`、`fill`、`hug`。
- 手绘图层可选择“扩展画布”和“缩放内容”；命令“UI：切换扩展画布／缩放内容”默认绑定 K，可通过原生快捷键配置修改。
- 图片支持 Stretch、Fit、Fill、Crop 和原始像素。单选图片层时粘贴替换内容，其他情况下创建图层；“粘贴为新图层”始终新建。
- 九宫格面板配置四边边距和拉伸／平铺模式。成品始终是一张实际目标尺寸纹理和一个 Cube。
- 普通图层双击进入原生绘画。图片／九宫格双击编辑源图，使用“应用到 UI”提交，或者取消。直接润色成品可先“转为绘画图层”。
- Frame 可横向／纵向自动排列，支持 padding、gap、对齐、固定尺寸、Fill、Hug、父级百分比加减像素。绝对定位子项不参与排列和 Hug。
- 使用原生保存和原生截图；项目不依赖自定义渲染器。

## Figma 风格操作

| 操作                  | 效果                     |
| --------------------- | ------------------------ |
| 左键拖动元素          | 移动图层／自动布局中排序 |
| 空白处左键拖动        | 框选                     |
| Shift 点击／框选      | 切换选择／添加选择       |
| 拖动八点框            | 调整尺寸                 |
| Shift 拖动控制点      | 等比                     |
| Option 拖动控制点     | 中心对称                 |
| Option 悬停其他元素   | 测量像素距离             |
| 中键或空格＋拖动      | 平移                     |
| 触摸板双指滑动        | 平移                     |
| 触摸板捏合／Ctrl 滚轮 | 围绕指针缩放视图         |
| 双击                  | 原生绘画／源图编辑       |
| Escape                | 取消当前拖动             |

“交互风格”和“2D／3D 视图”可独立切换。透视视图和原生交互使用 Blockbench 的导航方式。绘画期间保留原生画笔修饰键。

## 兼容性

原生客户端可以显示、修改、绘画和截图最后保存的内容。响应式布局、图片适配、源图编辑和九宫格重新生成需要插件。

插件规则保存在原生 `.bbmodel` 的 `unhandled_root_fields.mcui_studio` 字段，引用稳定 UUID；成品纹理内嵌。无插件保存后重开时检测几何或贴图差异，保留当前结果并暂停有冲突的规则。可选择采用当前结果或按规则重新生成。

项目使用 Generic Model 格式。转换为其他模型格式可能清除规则；不把这种格式转换视为可恢复的 UI 编辑工作流。

支持范围为静态像素 UI，不包含完整 Figma、游戏运行时绑定、动态文字、复杂网格或实时协作。原生透明度与截图抗锯齿行为仍由 Blockbench 决定。

## 验证

```sh
npm test                 # 独立业务与像素测试
npm run typecheck        # 含无 DOM 的业务内核配置
npm run check:boundaries # 自动检查宿主依赖隔离
npm run test:host        # 真实 Blockbench 页面集成测试
```

宿主测试要求 `.cache/blockbench` 是已构建 Web 版的测试副本，或用 `MCUI_HOST_DIR` 指向测试宿主。默认使用系统 Chrome，无需用户浏览器配置目录。详见 `docs/testing.md`。

设计、数据和适配策略见 `docs/implementation-plan.md` 与 `docs/architecture.md`。
